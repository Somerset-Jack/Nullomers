# Nullomer Generator

The repository contains four python files containing the code that generates Nullomers and identifies High Order Nullomers from a genome. 

## nullomer_controller.py

This file prompts the user to provide the directory containing the FASTA files, and what the desired k-mer length will be. 
It then calls the required fucntions in the other files to generate nullomers.

## index_kmers.py

Responsible for running Jellyfish and storing the k-mers that are present in the g

## generate_nullomers.py

* __generate_all_kmers__ - Creates a set of all possible k-mers for a given length
* __jf_to_dict__ - Turns the file generated by Jellyfish into a python dictionary
* __nullomer_generator__ - Compares the set of all possible k-mers with the list of present k-mers
* __nullomers_to_file__ - Writes the nullomers to a txt file
